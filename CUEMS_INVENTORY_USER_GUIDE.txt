USER ROLES
═══════════════════════════════════════════════════════════════════

DRIVER
  ✓ Take items (decrease quantity)
  ✓ Return items (increase quantity)
  ✓ View inventory levels
  ✗ Cannot do inventory checks
  ✗ Cannot access admin features

PROBIE
  ✓ Everything Drivers can do
  ✓ Perform inventory checks (update all quantities)
  ✗ Cannot manage users or add/remove items

ADMIN
  ✓ Everything Probies can do
  ✓ Invite new users
  ✓ Change user roles
  ✓ Add/remove inventory items
  ✓ View audit logs
  ✓ Export data to CSV

MAIN FEATURES
═══════════════════════════════════════════════════════════════════

📦 TAKE & RETURN (Default Page)
   Purpose: Quick inventory management during shifts
   
   How to Use:
   - Search for items using the search bar
   - Filter by cabinet (Left, Middle, Right, Floor, Armory)
   - Click RED "TAKE" button to remove 1 from inventory
   - Click BLUE "RETURN" button to add 1 back to inventory
   - Changes happen instantly - no confirmation needed
   - Color codes:
     • GREEN = Adequately stocked
     • YELLOW = Below minimal balance (reorder soon)
     • RED = Out of stock

   Tips:
   - One tap per action - super fast
   - Works great on phones
   - Updates in real-time across all devices

───────────────────────────────────────────────────────────────────

📊 INVENTORY LEVELS (Everyone)
   Purpose: Read-only view of all stock levels
   
   What You See:
   - Summary stats (Total Items, Low Stock, Out of Stock)
   - Full list of all items organized by cabinet and shelf
   - Current quantity vs. minimal balance
   - Item details (Item #, Vendor, Notes)

   When to Use:
   - Check stock before ordering supplies
   - Quick reference for what we have
   - See what needs to be restocked

───────────────────────────────────────────────────────────────────

✅ INVENTORY CHECK (Probies & Admins Only)
   Purpose: Update quantities after physical count
   
   How to Use:
   1. Physically count all items in your assigned area
   2. Open Inventory Check page
   3. Filter by cabinet if needed
   4. Type in the actual counted quantity for each item
   5. Admins can also edit: Min Balance, Vendor, Expiry dates, Notes
   6. Click "SUBMIT ALL CHANGES" when done
   
   Important:
   - All changes are grouped as ONE inventory check in audit logs
   - Can reset if you make mistakes before submitting
   - Shows "You have unsaved changes" warning
   - Changed items are highlighted in audit logs

───────────────────────────────────────────────────────────────────

📋 AUDIT LOGS (Admins Only)
   Purpose: Track who took what and when (for Columbia Health compliance)
   
   What You See:
   - All TAKE actions (who took items, when, quantity change)
   - All RETURN actions (who returned items)
   - Inventory Check sessions (collapsible folders)
   
   Features:
   - Search by item name or user email
   - Filter by action type (TAKE, RETURN, SET)
   - Export to CSV with date range:
     • Click "Export CSV"
     • Choose: All Time, Today, Last 7/30/90 Days, or Custom Range
     • Download for Columbia Health audits
   
   Inventory Check Details:
   - Click folder icon to expand
   - Changed items highlighted in yellow
   - See before/after for every item

───────────────────────────────────────────────────────────────────

⚙️ ADMIN PANEL (Admins Only)
   Purpose: Manage users and inventory items
   
   USER MANAGEMENT
   - Invite new users:
     • Enter their Columbia email
     • Select role (Driver/Probie/Admin)
     • They receive email to set password
   
   - Change user roles:
     • Use dropdown to change Driver → Probie → Admin
     • Changes take effect immediately
   
   - Delete users:
     • Click trash icon
     • Confirm deletion
     • Note: Cannot delete Supreme Admin (👑)
   
   INVENTORY MANAGEMENT
   - Add new items:
     • Fill in: Name, Cabinet, Shelf, Unit
     • Set initial quantity and minimal balance
     • Optional: Item #, Vendor, Notes/Expiry
     • Click "Add Item to Inventory"
   
   - Delete items:
     • Scroll to "Existing Items" section
     • Click trash icon next to item
     • Confirm deletion
     • Warning: Also deletes audit history for that item

───────────────────────────────────────────────────────────────────

🔑 CHANGE PASSWORD
   - Open menu (top-left hamburger icon)
   - Click "Change Password"
   - Enter current password
   - Enter new password twice
   - Click "Change Password"

TIPS & BEST PRACTICES
═══════════════════════════════════════════════════════════════════

FOR ON-SHIFT USE:
✓ Bookmark cuemsinventory.com on your phone
✓ Use Take & Return page - it's the fastest
✓ Don't worry about mistakes - everything is logged
✓ Changes sync in real-time - multiple people can use it at once

FOR PROBIES (Inventory Checks):
✓ Do physical counts carefully
✓ Double-check numbers before submitting
✓ Use cabinet filter to focus on one area at a time
✓ If you mess up, click Reset and start over
✓ All your changes are grouped as one check in audit logs

FOR ADMINS:
✓ Check audit logs weekly for unusual activity
✓ Review low stock items on Inventory Levels page
✓ Export audit logs monthly for Columbia Health records
✓ Invite new members as they join CUEMS
✓ You'll receive automated email every Sunday at 8 AM with:
  - Low stock alerts
  - Out of stock items
  - Weekly activity summary

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

"I forgot my password"
  → Click "Forgot password?" on login page
  → Enter your email
  → Check inbox for reset link

"I didn't receive invite email"
  → Check spam folder
  → Email comes from: noreply@cuemsinventory.com
  → Contact an admin if still not there

"Changes aren't saving"
  → Check your internet connection
  → Make sure you're clicking the submit/save button
  → Try refreshing the page

"I can't access Inventory Check/Admin Panel"
  → Check your role with an admin
  → Drivers can't access these features
  → You may need a role upgrade

"Real-time updates not working"
  → Refresh your browser
  → Check you're on latest version (hard refresh: Cmd+Shift+R)
  → Changes still save even if real-time isn't syncing

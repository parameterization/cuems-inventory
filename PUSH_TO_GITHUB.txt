STEP-BY-STEP: Push to GitHub

1. Go to: https://github.com/new

2. Create new repository:
   - Repository name: cuems-inventory
   - Description: CUEMS Inventory Management System
   - Private or Public: Choose Private (recommended for internal tool)
   - DO NOT initialize with README, .gitignore, or license (we already have these)

3. After creating, run these commands:

   git remote add origin https://github.com/YOUR_USERNAME/cuems-inventory.git
   git push -u origin main

That's it! Your code will be on GitHub.

Note: Make sure .env is NOT committed (it's in .gitignore already).
